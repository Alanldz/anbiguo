# 02 · 代码命名规范

> 总原则：**统一、可读、可搜索**。禁止拼音缩写、禁止无意义命名（`a1`、`tmp`、`test2`、`新建文件夹`）。
> 全文以英文命名，允许注释用中文。

## 一、通用命名格式

| 场景 | 格式 | 示例 |
| --- | --- | --- |
| 目录 / 文件夹 | 全小写 + 连字符 `kebab-case` | `question-bank`、`user-center` |
| 文件名（前端页面/组件） | `kebab-case` | `question-detail.vue` |
| 文件名（PHP 类） | `PascalCase`，与类名一致 | `QuestionBankService.php` |
| 类 / 接口 / 枚举 | `PascalCase` | `QuestionBankService`、`QuestionType` |
| 方法 / 函数 | `camelCase` | `getBankDetail()` |
| 变量 / 参数 | `camelCase` | `questionCount` |
| 常量 | 全大写下划线 `UPPER_SNAKE_CASE` | `MAX_UPLOAD_SIZE`、`ORDER_STATUS_PAID` |
| 数据库表 / 字段 | 全小写下划线 `snake_case` | `question_banks`、`created_at` |
| 布尔值 | `is_` / `has_` / `can_` 前缀 | `is_vip`、`has_answer`、`can_export` |
| 时间字段 | `_at` 结尾 | `created_at`、`paid_at`、`expired_at` |

## 二、前端（uni-app）命名

### 2.1 页面与路由

- 页面目录按业务模块划分，路径 `pages/模块名/页面名.vue`
  - `pages/index/index.vue` 首页
  - `pages/bank/list.vue` 题库列表
  - `pages/bank/detail.vue` 题库详情
  - `pages/exam/index.vue` 考试
  - `pages/mine/index.vue` 我的
- 分包页面统一放 `pages-sub/模块名/`，如 `pages-sub/practice/answer.vue`
- 路由 path 与文件路径完全一致，不额外起别名；路由 name 用 `PascalCase`，如 `BankDetail`
- 页面数量、分包划分必须在 `docs/01` 的页面清单中登记

### 2.2 组件

- 目录与文件名一致（便于自动导入）：`components/question-card/question-card.vue`
- 组件 `name` 用 `PascalCase`：`QuestionCard`
- 组件命名前缀按类型：`Base`（基础）、`App`（应用级）、`The`（唯一实例）
- 业务组件前缀用模块名：`BankHeader`、`ExamTimer`

### 2.3 变量与函数

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 组合式函数 | `use` 开头 | `useQuestionBank()`、`useUpload()` |
| 状态仓库 | `useXxxStore` | `useUserStore`、`useBankStore` |
| 事件处理 | `handle` 开头 | `handleSubmit()`、`handleUploadSuccess()` |
| 请求方法 | `动词 + 名词` | `fetchBankList()`、`createBank()`、`updateProfile()` |
| 布尔变量 | `is/has/can` 前缀 | `isLoading`、`hasMore` |
| 常量 | 全大写 | `PAGE_SIZE`、`QUESTION_TYPE_SINGLE` |

### 2.4 接口定义文件

- 按模块拆分：`src/api/bank.ts`、`src/api/exam.ts`、`src/api/user.ts`
- 每个函数对应一个后端接口，命名与后端接口台账编号一致（注释写明 `API ID`）
- 统一走 `src/utils/request.ts`，禁止在页面里直接调用 `uni.request`

```ts
// src/api/bank.ts
/** API-BANK-001 获取题库列表 */
export function fetchBankList(params: BankListParams) { ... }
```

### 2.5 静态资源命名

- 全部小写 + 连字符；图片命名 `模块-功能-状态.后缀`
- `icon-search.png`、`icon-upload-normal.png`、`banner-home-01.png`
- 多倍图：`icon-search@2x.png` / `@3x.png`
- 禁止中文文件名、禁止空格

### 2.6 样式类名

- 采用 BEM 风格：`block__element--modifier`
- `bank-card__title`、`bank-card__title--active`
- 设计变量集中定义：`--color-primary`、`--font-size-base`、`--spacing-md`

## 三、后端（PHP）命名

### 3.1 类与文件

| 类型 | 目录 | 命名 | 示例 |
| --- | --- | --- | --- |
| 控制器 | `app/Http/Controllers/Api/V1/` | `模块名Controller` | `QuestionBankController.php` |
| 用户后台控制器 | `app/Http/Controllers/Console/V1/` | 同上 | `QuestionBankController.php` |
| 服务类 | `app/Services/` | `模块名Service` | `QuestionBankService.php` |
| 数据访问 | `app/Repositories/` | `模块名Repository` | `QuestionRepository.php` |
| 模型 | `app/Models/` | 单数 `PascalCase` | `QuestionBank.php` |
| 请求验证 | `app/Http/Requests/` | `动作Request` | `StoreBankRequest.php` |
| 响应资源 | `app/Http/Resources/` | `模块名Resource` | `QuestionBankResource.php` |
| 枚举 | `app/Enums/` | 名词 `PascalCase` | `QuestionType.php`、`OrderStatus.php` |
| 队列任务 | `app/Jobs/` | `动作Job` | `ParseQuestionDocumentJob.php` |
| 中间件 | `app/Http/Middleware/` | `用途Middleware` | `AdminAuthMiddleware.php` |

### 3.2 方法命名（动词约定）

| 动作 | 前缀 | 示例 |
| --- | --- | --- |
| 查询列表 | `get` / `list` | `listBanks()` |
| 查询详情 | `get` / `find` | `getBankDetail()` |
| 新增 | `create` / `store` | `createBank()` |
| 更新 | `update` | `updateBank()` |
| 删除 | `delete` / `destroy` | `deleteBank()` |
| 判断 | `is` / `check` | `isVip()`、`checkQuota()` |
| 计算 | `calc` | `calcScore()` |
| 转换 | `to` | `toArray()` |

### 3.3 路由命名

- 资源式复数：`/api/v1/question-banks`、`/api/v1/question-banks/{id}/questions`
- 路由名点号分隔：`bank.list`、`bank.detail`、`exam.submit`
- 禁止动词式 URL（`/getBankList`），动作用 HTTP Method 表达

## 四、Git 命名

| 项 | 规范 | 示例 |
| --- | --- | --- |
| 分支 | `类型/简述` | `feature/bank-import`、`fix/exam-timer` |
| 提交 | `类型(范围): 描述` | `feat(bank): 支持 Excel 批量导题` |
| 提交类型 | feat / fix / docs / style / refactor / perf / test / chore / build | — |

详见 `07-项目管理与协作规范.md`。

## 五、禁止事项清单

1. ❌ 拼音命名：`tikuController`、`shijuan`、`yonghu`
2. ❌ 无意义缩写：`qb`、`usr`、`tmpData`、`data1`
3. ❌ 中文文件名与中文目录名
4. ❌ 跨层直连：控制器里写 SQL、前端页面里直接发请求
5. ❌ 把 KEY / 密钥 / 域名硬编码在代码里（必须走配置中心）
6. ❌ 同一含义多个词：统一用 `questionBank`，不要时而 `tiku` 时而 `bank` 时而 `library`
7. ❌ 提交调试代码：`console.log`、`var_dump`、被注释的大段旧代码
