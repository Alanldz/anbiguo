## 文档维护规则

1. **同步登记**：新增数据表 → 更新 `03` 的登记表；新增接口 → 更新 `04` 的登记表；新增 OSS 目录 → 更新 `05`；新增后台页面 → 更新 `06`。
2. **变更留痕**：规范变更必须记录「日期 / 变更人 / 变更内容 / 影响范围」。
3. **不做口头约定**：任何未写入文档的约定视为无效。
4. **待确认标注**：未拍板的决策统一用 `【待确认】` 标注，确认后移除标记并写入正文。
