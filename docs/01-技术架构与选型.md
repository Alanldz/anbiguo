### 隔离要求（硬约束）

| 项 | 客户端 API | 用户后台 | 总后台 |
| --- | --- | --- | --- |
| 路由前缀 | `/api/v1` | `/console-api/v1` | `/admin-api/v1` |
| 代码目录 | `server/app/Http/Controllers/Api` | `server/app/Http/Controllers/Console` | `admin/api/` |
| 鉴权守卫 | `auth:client` | `auth:console` | `auth:admin`（独立密钥） |
| 域名 | `api.xxx.com` | `console.xxx.com` | `admin.xxx.com` |
| 部署目录 | `/www/wwwroot/app-server` | `/www/wwwroot/app-console` | `/www/wwwroot/app-admin` |
| 数据库账号 | `app_client` | `app_console` | `app_admin` |
| 访问限制 | 公开 | 公开 | IP 白名单 / VPN |

> 总后台目录、代码、配置、数据库账号、Session/JWT 密钥与其余部分**零共享**，即使其他模块被攻破也无法横向进入总后台。

## 五、多端兼容策略

1. **条件编译**：平台差异用 `#ifdef MP-WEIXIN` / `#ifdef APP-PLUS` / `#ifdef H5` 包裹，禁止在业务逻辑里散落判断。
2. **能力抽象**：登录、支付、分享、扫码、文件上传等平台差异能力统一封装到 `src/utils/platform/`，业务层只调用统一方法。
3. **样式统一**：使用 `rpx` 布局；颜色、字号、间距集中在 `styles/variables.scss`，不写魔法值。
4. **分包加载**：首页/Tab 页放主包，题库详情、练习答题、考试等大模块放 `pages-sub/`，控制主包体积以通过小程序审核。
5. **登录差异**：小程序走 `wx.login` → code 换 openid；App/H5 走手机号验证码 + 密码；统一由后端换发业务 Token。

## 六、安全基线

- 全站 HTTPS；接口签名 + Token 鉴权；敏感接口限流（Redis）
- 密码 `bcrypt` 存储；第三方密钥 AES 加密入库，后台展示脱敏
- 上传文件类型白名单 + 大小限制 + 病毒扫描（可接第三方）
- SQL 一律走 ORM/参数绑定，禁止字符串拼接
- 操作日志：总后台所有写操作留痕（操作人 / IP / 时间 / 前后值）
