# 08 · 服务器部署指南（宝塔）

> 适用：Linux 服务器 + 宝塔面板。目标：把「识途刷题」后端 API 跑起来，并完成第三方服务配置。
> 阅读方式：按「阶段一 → 阶段五」顺序执行，每阶段结束有 ✅ 验证点。
> 所有命令默认在 **SSH 终端**（宝塔左侧「终端」即可）以 root 执行。

## 一、环境清单（宝塔要装什么）

### 1.1 软件商店安装

| 组件 | 版本要求 | 用途 | 安装方式 |
| --- | --- | --- | --- |
| **Nginx** | 1.24+ | Web 服务器 | 软件商店 → 运行环境 |
| **MySQL** | **8.0** | 主数据库（5.7 不支持本项目的 utf8mb4 校验与默认值语法） | 软件商店 → 数据库 |
| **PHP** | **8.3**（无法选 8.3 时装 8.2 并告知我，需改 composer.json） | 后端运行时 | 软件商店 → 运行环境 |
| **Redis** | 7.x | 缓存 / 队列 / 会话 | 软件商店 → 运行环境 |
| **Supervisor 管理器** | 最新 | 常驻队列进程（导题解析等异步任务） | 软件商店 → 插件 |
| phpMyAdmin | 最新 | 数据库管理（可选） | 软件商店 → 插件 |

> **不需要装**：Node.js、Java、Docker、Apache。前端在你本地电脑构建后上传静态文件即可。

### 1.2 PHP 8.3 设置（关键，漏了会报错）

**① 安装扩展**：宝塔 → 软件商店 → PHP 8.3 → 设置 → 安装扩展，勾选：

```
fileinfo   redis   pdo_mysql   mbstring   bcmath   zip   gd   exif   intl   pcntl
```

**② 解除禁用函数**：PHP 8.3 → 设置 → 禁用函数，从列表中**删除**以下函数（composer 与队列必需）：

```
putenv  proc_open  pcntl_signal  pcntl_signal_dispatch  pcntl_fork  pcntl_wait  pcntl_alarm  symlink  shell_exec
```

**③ 性能参数**：PHP 8.3 → 设置 → 性能调整，建议 `max_execution_time=300`、`memory_limit=512M`、`upload_max_filesize=200M`、`post_max_size=210M`（导题要传大文档）。

**④ Redis 设密码**：软件商店 → Redis → 设置 → 配置修改，`requirepass 你的Redis密码`，改完重启。

### 1.3 安装 Composer（SSH 执行）

```bash
cd /tmp
curl -sS https://getcomposer.org/installer -o composer-setup.php
php /www/server/php/83/bin/php composer-setup.php --install-dir=/usr/local/bin --filename=composer
composer config -g repos.packagist composer https://mirrors.aliyun.com/composer/   # 国内加速
composer -V   # ✅ 验证点：输出 Composer 2.x
```

> 若 `php` 命令不存在，用完整路径 `/www/server/php/83/bin/php`，或 `ln -sf /www/server/php/83/bin/php /usr/local/bin/php`。

## 二、域名与站点规划（先备案，再部署）

| 域名（示例） | 指向 | 用途 | 状态 |
| --- | --- | --- | --- |
| `api.你的域名.com` | server/public | 客户端 API + 用户后台 API | 本次部署 |

## 三、部署代码（阶段二）

### 3.1 服务器拉代码

```bash
# ① 生成服务器专属部署密钥（只读 Deploy Key，更安全）
ssh-keygen -t ed25519 -C "anbiguo-server" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub
# ② 复制上面输出的公钥 → GitHub 仓库 → Settings → Deploy keys → Add（不要勾选 write）
ssh -T git@github.com          # ✅ 输出 Hi Alanldz! 即通

# ③ 克隆代码
mkdir -p /www/wwwroot && cd /www/wwwroot
git clone git@github.com:Alanldz/anbiguo.git
cd anbiguo/server
```

### 3.2 安装依赖并初始化

```bash
cd /www/wwwroot/anbiguo/server
composer install --no-dev --optimize-autoloader    # 首次约 2-5 分钟

cp .env.example .env
php artisan key:generate
```

### 3.3 编辑 `.env`（宝塔文件管理器打开 `/www/wwwroot/anbiguo/server/.env`）

| 配置项 | 填什么 | 生成/说明 |
| --- | --- | --- |
| `APP_ENV` | `production` | 生产必改 |
| `APP_DEBUG` | `false` | 生产必改 |
| `APP_URL` | `https://api.你的域名.com` | |
| `DB_DATABASE` | `anbiguo` | 下一步建库 |
| `DB_USERNAME` / `DB_PASSWORD` | `app_client` / 对应密码 | 先留空，建库后回填 |
| `REDIS_PASSWORD` | 你的 Redis 密码 | 1.2 ④ 设置的 |
| `JWT_SECRET_CLIENT` | 64 位随机串 | SSH 执行 `php -r "echo bin2hex(random_bytes(32));"` |
| `JWT_SECRET_CONSOLE` | 另一个 64 位随机串 | 同上，**必须与 CLIENT 不同** |
| `CONFIG_ENCRYPT_KEY` | base64 随机串 | `php -r "echo base64_encode(random_bytes(32));"` ⚠️ 生成后妥善保存，**永不可换**（换了第三方密钥全部解不开） |
| `ADMIN_INIT_PASSWORD` | 临时管理员密码 | 首次 seed 创建账号用，登录后立即改 |
| `SMS_DEBUG_SHOW_CODE` | `false` | true 会把验证码直接返回给前端 |

### 3.4 建库与账号（宝塔 → 数据库）

```bash
mysql -uroot -p < /www/wwwroot/anbiguo/server/database/sql/00_create_database.sql
# 然后修改三套账号密码（把 sql 文件里的默认密码换成强密码）：
mysql -uroot -p -e "ALTER USER 'app_client'@'127.0.0.1' IDENTIFIED BY '新密码A'; ALTER USER 'app_console'@'127.0.0.1' IDENTIFIED BY '新密码B'; ALTER USER 'app_admin'@'127.0.0.1' IDENTIFIED BY '新密码C'; FLUSH PRIVILEGES;"
```

**验证账号隔离**（应分别输出 0 / 0 / 8）：

```bash
mysql -uapp_client -p新密码A -e "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='anbiguo' AND table_name LIKE 'sys\_%';"
mysql -uapp_admin  -p新密码C -e "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='anbiguo' AND table_name LIKE 'sys\_%';"
```

### 3.5 跑迁移与初始化数据

```bash
cd /www/wwwroot/anbiguo/server
# 迁移需要 DDL 权限，临时用 app_admin 账号：
DB_USERNAME=app_admin DB_PASSWORD=新密码C php artisan migrate --force
DB_USERNAME=app_admin DB_PASSWORD=新密码C php artisan db:seed --force
# 回填 .env 的 DB_USERNAME/DB_PASSWORD 为 app_client + 新密码A
php artisan config:clear && php artisan cache:clear
```

✅ **验证点**：`php artisan migrate:status` 全部 `[Ran]`；数据库里 `sys_configs` 有 33 条、`bank_categories` 有 14 条。

## 四、建站点与 Nginx（阶段三）

### 4.1 宝塔 → 网站 → 添加站点

| 站点域名 | 根目录 | PHP 版本 |
| --- | --- | --- |
| `api.你的域名.com` | `/www/wwwroot/anbiguo/server/public` | 8.3 |
| `h5.你的域名.com` | `/www/wwwroot/anbiguo/h5-dist`（先建空目录） | 纯静态 |

### 4.2 api 站点伪静态 / 配置（站点 → 设置 → 配置文件，在 server 块加）

```nginx
root /www/wwwroot/anbiguo/server/public;
index index.php;

location / {
    try_files $uri $uri/ /index.php?$query_string;
}

location ~ \.php$ {
    fastcgi_pass unix:/tmp/php-cgi-83.sock;
    fastcgi_index index.php;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    include fastcgi_params;
}
```

### 4.3 目录权限

```bash
cd /www/wwwroot/anbiguo/server
chown -R www:www storage bootstrap/cache
chmod -R 775 storage bootstrap/cache
```

### 4.4 SSL 证书

站点 → 设置 → SSL → Let's Encrypt 一键申请（api 与 h5 两个站点都要），并开启「强制 HTTPS」。

### 4.5 H5 前端上线

本地电脑：`cd client && npm run build:h5` → 产物在 `client/dist/build/h5/` → 宝塔文件管理器上传全部内容到 `/www/wwwroot/anbiguo/h5-dist/`。
✅ 浏览器打开 `https://h5.你的域名.com` 看到识途刷题首页（Mock 数据模式）。

### 4.6 总后台部署（admin/ 独立应用，已开发）

**后端**（独立 Laravel 应用，域名 `admin-api.你的域名.com`）：

```bash
cd /www/wwwroot/anbiguo/admin/api
composer install --no-dev --optimize-autoloader
cp .env.example .env
# 编辑 .env：DB_USERNAME=app_admin；APP_KEY 必须与 server/.env 完全一致（sys_configs 密文共享解密）；
# CACHE_PREFIX 必须与 server/.env 一致（配置缓存跨应用联动）；JWT_SECRET_ADMIN 单独生成（与其他三个密钥都不同）
```

宝塔新建站点 `admin-api.你的域名.com` → 根目录指到 `admin/api/public`，Nginx 配置同 4.2。

**前端**（独立 Vue3 工程）：

```bash
# 本地电脑
cd admin/web
npm install && npm run build     # 产物 dist/
# 上传 dist/ 全部内容到宝塔站点 admin.你的域名.com 的根目录（纯静态）
```

✅ **验证点**：打开 `https://admin.你的域名.com` → 登录页 → 用初始管理员账号登录（密码来自 server 的 `SystemInitSeeder`，`ADMIN_INIT_PASSWORD`，登录后立即修改）；仪表盘出统计数据即通。

**三个易错点**（配错就白屏/解不开密文）：
1. admin/api 的 `APP_KEY` ≠ 新生成的，必须复制 server/.env 的 `APP_KEY`
2. admin/api 的 `CACHE_PREFIX` 必须与 server/.env 一致（默认 `anbiguo_cache`）
3. `JWT_SECRET_ADMIN` 必须独立生成，不能复用 CLIENT/CONSOLE 密钥

✅ **验证点**：浏览器打开 `https://api.你的域名.com/api/v1/config/bootstrap` 返回 JSON（而不是 404/HTML）。
